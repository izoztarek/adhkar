# رفيق — تطبيق الكارت

موقع ثابت بالكامل (HTML و CSS و JavaScript) من غير أي فريمورك ولا npm.
بيترفع على GitHub Pages زي ما هو، ويشتغل على الرابط: `https://app.rafeeq.shop`

---

## ١. اللي هتحتاج تعدّله

| عايز تغيّر | الملف |
|---|---|
| الأذكار (العناوين، النص، المصدر، عدد المرات، الصوت) | `js/content.js` |
| المواقيت، الموقع، عدّاد الزيارات، الأهداف المقترحة | `js/config.js` |
| ملفات الصوت | `assets/audio/` |
| رقم نسخة التحديث (بعد أي تعديل) | `sw.js` ← `VERSION` |

### المحتوى

كل ذكر في `js/content.js` له: `title` و `text` (اختياري) و `source` (اختياري) و `repeat` و `audio`.

- **المحتوى الحالي مؤقت بالكامل.** العناوين بين `[ ]` والأصوات نغمات تجريبية.
- **ما تحطش أي نص ديني غير بعد مراجعته على المرجع** (حصن المسلم).
- لو `text` فاضي، الشاشة بتعرض العنوان بس — يعني ينفع تطلق بالصوت والعناوين، وتضيف النص بعدين.
- لما تخلص المحتوى النهائي خلّي `contentReady: true` في `js/config.js` عشان شريط "نسخة تجريبية" يختفي.

### الصوت — طريقتين

**(أ) ملف واحد لكل قسم + توقيت بداية كل ذكر** (الأضمن والشاشة مقفولة، خصوصًا على الآيفون):

```js
{ id: 'm01', title: 'آية الكرسي', repeat: 1, audio: { src: 'assets/audio/morning/morning.mp3', start: 0 } },
{ id: 'm02', title: '...',        repeat: 3, audio: { src: 'assets/audio/morning/morning.mp3', start: 42.5 } },
```

**(ب) ملف لكل ذكر:**

```js
{ id: 'e01', title: '...', repeat: 1, audio: { src: 'assets/audio/evening/evening-01.mp3' } },
```

**التكرار:** `repeatsRecorded: true` معناه إن التكرار متسجّل جوه الصوت (يتشغل مرة واحدة).
`false` معناه إن الذكر متسجّل مرة واحدة والموقع بيكرره `repeat` مرة.

**تجهيز الملفات:** MP3 مونو 64kbps كفاية جدًا للصوت البشري وبيخلّي الملفات صغيرة.
لو عندك ffmpeg:

```
ffmpeg -i input.wav -ac 1 -b:a 64k output.mp3
```

لو بدّلت تسجيل بنفس اسم الملف، زوّد `AUDIO_VERSION` في `sw.js` عشان الأجهزة تنزّل الجديد.

## ٢. الرفع على GitHub Pages وربط الدومين

1. اعمل Repository جديد على GitHub (مثلًا `rafeeq-app`) وارفع كل الملفات اللي في الفولدر ده (بما فيها `CNAME` و `.nojekyll`).
2. من الـ Repository: **Settings ← Pages ← Build and deployment**: اختار `Deploy from a branch`، والفرع `main`، والفولدر `/ (root)`.
3. في نفس الصفحة، تحت **Custom domain** اكتب `app.rafeeq.shop` واحفظ.
4. في إعدادات الـ DNS بتاعة الدومين `rafeeq.shop` (لو الدومين متسجّل من Shopify، الإعدادات دي من صفحة الدومينات في Shopify): ضيف سجل:
   - النوع: `CNAME`
   - الاسم: `app`
   - القيمة: `<اسم-حسابك>.github.io`
5. استنى لحد ما GitHub يأكّد الدومين، وبعدين فعّل **Enforce HTTPS** (لازم عشان الـ PWA والأوفلاين يشتغلوا).

> **مهم:** الاستضافة لازم تدعم طلبات Range للصوت. GitHub Pages بيدعمها. السيرفر المحلي البسيط (`python -m http.server`) ما بيدعمهاش، فالتنقّل جوه ملف الصوت الواحد ممكن يبوظ في الاختبار المحلي بس.

## ٣. أكواد الكروت

افتح `https://app.rafeeq.shop/tools/card-ids.html`، اكتب عدد الكروت واسم الدفعة، ونزّل ملف CSV.
كل سطر فيه رابط فريد زي: `https://app.rafeeq.shop/?c=K7Q2M9ABCD`

- الكود بيتسجل على جهاز العميل أول ما يلمس الكارت، والرابط بيتنضّف من شريط العنوان.
- الكود دلوقتي **ما بيتبعتش لأي مكان.** هو أساس لمميزات بعدين (صفحة خاصة للكارت المخصص، تفعيل الكارت) ودي هتحتاج سيرفر صغير وقتها.
- احتفظ بكل ملفات CSV في شيت رئيسي واحد.
- الروابط من غير كود (`https://app.rafeeq.shop/`) شغالة عادي، بس من غير محاولة التشغيل التلقائي.
- **الكروت القديمة:** لو كانت بتفتح رابط تاني، خلّي الرابط القديم يحوّل (redirect) على `https://app.rafeeq.shop/?c=legacy`. وأي مسار غلط على الدومين الجديد بيرجع للتطبيق لوحده (`404.html`).

## ٤. المواقيت

حسب فتوى دار الإفتاء المصرية (يناير 2024):

- **من الفجر للزوال (الضهر):** أذكار الصباح
- **من الزوال للفجر:** أذكار المساء
- **اليوم في العدّاد** بيبدأ من الفجر.

الحساب على الجهاز نفسه، بطريقة الهيئة المصرية العامة للمساحة (زاوية الفجر 19.5°)، وعلى إحداثيات القاهرة، من غير إنترنت ومن غير طلب الموقع. التوقيت الصيفي والشتوي بيتظبطوا لوحدهم من ساعة الموبايل.

تقدر تغيّر أي حد في `config.js` لساعة ثابتة بدل الوقت الشرعي، مثلًا `{ from: '05:00', to: '12:00' }`.

## ٥. الاختبار

**وضع الاختبار:** ضيف `?debug` للرابط عشان تشوف المواقيت المحسوبة والحالة.
وتقدر تجرّب أي وقت كده:

```
https://app.rafeeq.shop/?debug&now=2026-10-03T21:00:00%2B03:00
```

**قبل الإطلاق، جرّب على أجهزة حقيقية:**

- [ ] آيفون (Safari): لمسة الكارت ← الإشعار ← الموقع يفتح ← ضغطة "اضغط وابدأ" ← الصوت يشتغل
- [ ] آيفون: اقفل الشاشة أثناء التشغيل — الصوت يكمّل؟ التحكم يظهر على شاشة القفل؟
- [ ] أندرويد (Chrome): نفس الخطوات، وبعدين ثبّت التطبيق على الشاشة الرئيسية وجرّب لمسة الكارت تاني (ممكن يشتغل تلقائي)
- [ ] اقفل الإنترنت بعد أول استخدام — الموقع والصوت يشتغلوا؟
- [ ] جرّب مع إعداد الخط الكبير في الموبايل
- [ ] كمّل أذكار الصباح لآخرها — العدّاد زاد يوم؟ وتكرارها في نفس اليوم ما بيزودش؟

## ٦. عدّاد الزيارات (مقفول افتراضيًا)

لو حبيت تعرف عدد الزيارات من غير كوكيز ومن غير أي بيانات شخصية:

1. اعمل حساب مجاني على Cloudflare وافتح **Web Analytics**، وضيف الموقع `app.rafeeq.shop`.
2. انسخ التوكن وحطه في `config.js` ← `analytics.cloudflareToken`.

طول ما التوكن فاضي، مفيش أي حاجة بتتبعت لأي مكان.

## ٧. الخصوصية

- كل البيانات (عدد الأيام، الهدف، الاسم، كود الكارت) متخزنة على جهاز المستخدم بس.
- مفيش حسابات ولا سيرفر ولا تتبّع.
- لو المستخدم مسح بيانات المتصفح، التقدّم بيتمسح معاها.

## ٨. هيكل الملفات

```
index.html              الصفحة الوحيدة (الرئيسية + التشغيل + النهاية + الإعدادات)
manifest.webmanifest    إعدادات التثبيت على الشاشة الرئيسية
sw.js                   الأوفلاين وتخزين الصوت
404.html                يحوّل أي رابط غلط للتطبيق
CNAME                   الدومين
css/style.css           التصميم كله
js/config.js            الإعدادات
js/content.js           المحتوى
js/prayer.js            حساب الفجر والزوال
js/progress.js          عدّاد الأيام والهدف
js/storage.js           التخزين الآمن
js/player.js            مشغّل الصوت
js/app.js               ربط الواجهة
tools/card-ids.html     مولّد أكواد الكروت
assets/fonts/           IBM Plex Sans Arabic و Amiri (رخصة OFL مرفقة)
assets/icons/           الأيقونات (مؤقتة — بدّلها باللوجو الرسمي بنفس الأسماء والمقاسات)
assets/images/og.png    صورة المشاركة (مؤقتة — 1200×630)
assets/audio/           الصوت (مؤقت)
```

**اللوجو:** الكلمة "رفيق" في أعلى الرئيسية مكتوبة بالخط. لو عايز تستخدم ملف اللوجو الرسمي، حط `logo.svg` في `assets/images/` وبدّل في `index.html` السطر:
`<span class="wordmark" aria-label="رفيق">رفيق</span>`
بـ:
`<img class="wordmark" src="assets/images/logo.svg" alt="رفيق" height="24">`
